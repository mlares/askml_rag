# Project scope                                                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                                  
## Goal                                                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                                                  
Build an evaluation-first RAG system that answers questions about Marcelo                                                                                                                                                                                                       
Lares's public research, projects, teaching, and professional experience using                                                                                                                                                                                                  
verifiable source citations.                                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                                
## Intended users                                                                                                                                                                                                                                                               
                                                                                                                                                                                                                                                                                
Recruiters, collaborators, and visitors exploring the public portfolio.                                                                                                                                                                                                         
                                                                                                                                                                                                                                                                                
## MVP corpus                                                                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                                                
20–30 curated, public documents, including a professional biography, selected                                                                                                                                                                                                   
publications, project descriptions, teaching material, and public web content.                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                
## Required behavior                                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                                                
- Retrieve relevant source passages.                                                                                                                                                                                                                                            
- Cite the documents supporting each answer.                                                                                                                                                                                                                                    
- Abstain when the corpus does not contain sufficient evidence.                                                                                                                                                                                                                 
- Record retrieval configuration, latency, and evaluation results.                                                                                                                                                                                                              
                                                                                                                                                                                                                                                                                
## Non-goals for the MVP                                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                                                                
- Impersonating Marcelo or answering from unstated personal knowledge.                                                                                                                                                                                                          
- Private, confidential, or NDA-protected information.                                                                                                                                                                                                                          
- Agents, fine-tuning, reranking, multi-provider routing, or public deployment.
